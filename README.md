Cinema Hall Management System – Database Setup & Project Report

This repository contains the SQL Server database script, setup guide, and report for the Cinema Hall Management System, a C# Windows Forms desktop application for cinema operations: movie scheduling, seat reservation, food ordering, payment, ticketing, and revenue reporting.

Original project: borno-beep/Cinema-Hall-Management-System All application source code and the original SQL script belong to the original author. This repository was prepared for a course assignment (download, configure, run, and test the project).
